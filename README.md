# Employee Onboarding Portal

## Pages & Features

### 1. Dashboard
- New hires this month / quarter
- Onboarding progress overview (how many steps completed)
- Pending tasks for HR / managers
- Time-to-productivity metrics

### 2. Onboarding Plans
- Create onboarding plan templates by role / department
- Define milestones & checklist items
- Set due dates & responsible persons
- Assign onboarding buddy / mentor

### 3. New Hire View
- Welcome page with company intro & culture
- Personal info form (bank details, emergency contacts)
- Document upload (ID, tax forms, certifications)
- Checklist of required tasks (read policies, set up tools)
- Progress tracker (step-by-step)

### 4. Task Management
- HR tasks: create accounts, order equipment, assign desk
- Manager tasks: schedule 1-on-1s, set goals
- IT tasks: provision email, tools, access permissions
- Task completion tracking per hire

### 5. Knowledge Hub
- Company handbook & policies
- Training videos & resources
- FAQ section
- Team introductions & org chart

### 6. Employee Directory
- Browse team members by department
- Profile cards with photo, role, contact info
- Direct message / email link

### 7. Reports
- Onboarding completion rates
- Average onboarding duration
- Task bottleneck analysis
- New hire satisfaction survey results

### 8. Settings
- Onboarding template management
- Notification & reminder schedules
- Role-based access configuration
- Integration settings (email, chat, HRIS)
